# Time Tracker

A shift management system that helps organizations track employee work hours, manage schedules, and monitor attendance.

## Features

- Employee shift scheduling
- Time clock functionality
- Attendance tracking
- Schedule management
- Reports generation
- User-friendly interface

## Installation

1. Clone the repository:
2. Install dependencies:
3. Start the development server:
4. Access the application through your web browser at `http://localhost:8000`

5. Log in with your credentials to:
   - Create and manage employee schedules
   - Track work hours
   - Generate attendance reports
   - Manage employee information

## Technologies Used

- Frontend: React.js
- Backend: Node.js
- Database: MongoDB
- Authentication: JWT
