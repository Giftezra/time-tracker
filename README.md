# Time Tracker Application

A comprehensive time tracking solution built with React Native (Expo) for the
frontend and Django for the backend. This application helps businesses manage
employee schedules, track work hours, and handle various management tasks.

## Features

- Employee shift scheduling
- Time clock functionality
- Attendance tracking
- Schedule management
- Reports generation
- User-friendly interface
- Chat functionality
- Geo-Fencing
- Push Notifications
- Location Tracking
- Background Services
- In-App Purchases
- User Management
- Role-Based Access Control
- Task Management
- Project Management
- Reporting and Analytics


## Installation

1. Clone the repository:
2. Install dependencies:
   # Run npm install in the frontend directory
   # Run pip install in the server directory

3. Start the development server:
   # Cd into the server directory and run python manage.py runserver
   # Cd into the frontend directory and run npm start

4. Access the application through your web browser at `http://localhost:8000`

5. Open another terminal and run ngrok http 8000
6. Copy the ngrok url and paste it into the .env file in the frontend directory
7. Run the app on your phone using Expo Go or on the Web using localhost:8000
8. Create a new account or log in with your credentials
9. Create and manage employee schedules
   - Track work hours
   - Generate attendance reports
   - Manage employee information

## Technologies Used

- Frontend: React Native (Expo)
- Backend: Django
- Database: SQLite for local development and PostgreSQL for production
- Authentication: JWT
- Payment: Stripe
- Reporting and Analytics: React Native Gifted Charts
- Caching: Redis
- Geofencing: Geofencing for location tracking
- Push Notifications: Firebase for Android and Apple Push Notifications for iOS
- Location Tracking: Location Tracking for location tracking
